# OCR цен

`cyrillic_rec.onnx` — `cyrillic_PP-OCRv5_rec_mobile`, опубликованная RapidAI ONNX-версия модели PaddleOCR для кириллицы. Используется только для чтения цен; игровая модель `bestV1` не изменялась.

- [Исходная модель](https://www.modelscope.cn/models/RapidAI/RapidOCR/resolve/v3.9.2/onnx/PP-OCRv5/rec/cyrillic_PP-OCRv5_rec_mobile.onnx)
- [Документация RapidOCR и список моделей](https://rapidai.github.io/RapidOCRDocs/latest/model_list/)
- [PaddleOCR](https://github.com/PaddlePaddle/PaddleOCR)
- [Лицензия PaddleOCR](LICENSE.txt)

SHA256: `90f761b4bfcce0c8c561c0cb5c887b0971d3ec01c32164bdf7374a35b0982711`.

Распознавание работает локально через ONNX Runtime. Загрузка моделей при запуске программы не требуется.
